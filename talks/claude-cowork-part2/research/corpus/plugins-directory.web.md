## Key claims
- "Plugins bundle multiple MCPs, skills, and tools into a single download. Instead of installing each component separately, you get everything you need in one click."
- El directorio mezcla plugins de Anthropic, de terceros con nombre propio (GitHub, Slack, Figma, Atlassian, Stripe, Microsoft, Google, etc.) y de la comunidad; el catálogo supera los cien plugins, con fuerte sesgo a desarrollo de software (LSPs, code review, deploy).
- Revisión: "Plugins are submitted by developers in the community. We perform basic automated review on submissions before adding them to the directory, and plugins with an 'Anthropic Verified' badge have undergone additional review from a quality and safety perspective."
- Advertencia: "Community plugins may install unverified, third party software that could be malicious or result in unintended behavior." Cada plugin publica enlaces para revisar su contenido antes de instalar.

## Definitions and terminology
- **Anthropic Verified:** insignia de revisión adicional de calidad y seguridad.

## Evidence and examples
- Ejemplos de plugins mantenidos por Anthropic: Skill Creator, Code Review, Frontend DesignCraft, Security Guidance. Ejemplos de terceros oficiales: GitHub, Slack (MCP), Figma, Atlassian, Stripe. La mayoría del catálogo apunta a desarrollo; los plugins de negocio para Cowork están en la lista de 11 del blog (cowork-plugins-blog.web.md).
