# Use Claude's chat search and memory to build on previous context (Claude Help Center)

## Provenance
- Original location: fetch web directo durante Step 5 (Review), sin captura en research/web/
- Format: html
- Author / source (if known): Anthropic - Claude Help Center
- Date of original (if known): vigente al 2026-08-03

## Key claims
- Claude genera entradas de Memory a partir de las conversaciones y las lee, escribe y actualiza mientras se conversa, no según un cronograma diario fijo.
- El usuario puede decirle a Claude qué recordar o qué cambiar; el cambio se aplica a la siguiente conversación.
- Settings > Memory permite ver entradas, editarlas o eliminarlas. También permite pausar o reiniciar Memory.
- Las entradas de un Project tienen un espacio de Memory y resumen separados.

## Definitions and terminology
- **Entrada de Memory:** unidad de contexto guardada y agrupada por categoría.
- **Pausar Memory:** conserva lo existente, pero deja de usarlo y de crear nuevas entradas.
- **Reiniciar Memory:** elimina de forma permanente las memorias, incluidas las de Projects.

## Evidence and examples
- Ejemplo de corrección explícita: decirle a Claude qué debe recordar directamente desde el chat, sin salir de la conversación.

## Inconsistencies / open questions
- La experiencia nueva de Memory indica que aún no está disponible para Cowork, mientras que la documentación específica de Cowork confirma Memory en Projects. Para esta clase, presentar la interfaz como dependiente del plan y la versión; conservar la regla operativa de revisar, editar y borrar.
