# Organize your tasks with projects in Claude Cowork (Claude Help Center)

## Provenance
- Original location: fetch web directo durante Step 5 (Review), sin captura en research/web/

## Key claims
- Cada Project de Cowork tiene sus propios archivos, contexto, Instructions y Memory.
- Memory está habilitada para Projects de Cowork: Claude puede recordar el contexto de tareas ejecutadas en un Project y aplicarlo en tareas futuras del mismo Project.
- El alcance es por Project: lo aprendido en un Project no se transfiere a otros.
- Los Projects de Cowork son locales al escritorio y no tienen sincronización en la nube.

## Definitions and terminology
- **Memory de Project:** contexto que Claude puede retener de tareas ejecutadas dentro de un Project de Cowork.

## Evidence and examples
- La página enumera Memory junto con Instructions, tareas programadas y contexto como componentes propios de cada Project.

## Inconsistencies / open questions
- La documentación general de Memory diferencia experiencias según plan y despliegue. La interfaz concreta puede variar, pero la documentación específica de Cowork confirma que Memory está habilitada en Projects.
